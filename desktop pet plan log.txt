==============================
一、專案目標
==============================

Nova 是一個 Windows 桌面 AI 助手。

並非以「桌寵遊戲」為目標，而是以「可長期維護、可持續擴充」的桌面助手平台為目標。

第一版功能保持簡潔，但整體架構需預留未來功能擴充能力。

設計原則：

- Modular（模組化）
- Low Coupling（低耦合）
- High Cohesion（高內聚）
- Config Driven（設定檔驅動）
- Easy Maintenance（易於維護）
- Plugin Ready（預留插件能力）

負責：

HTTP Request

History

不得依賴 UI。

------------------------------

Config

負責：

讀寫 ini

環境變數

十一、事件(Event Bus)
==============================

所有模組透過 Event Bus 通訊。

例如：

Pet Click

Bubble Open

Message Send

Message Receive

Animation Start

Animation End

API Error

避免模組直接互相呼叫。

==============================
十八、設計原則
==============================

任何模組皆可獨立移除。

例如：

移除 AI

桌寵仍正常。

移除 Bubble

桌寵仍正常。

移除 Plugin

主程式仍正常。

所有未來功能皆應以新增模組方式完成，而非修改 Core。
